# Proyecto Tienda (Base Maven)

Proyecto base para el entregable: contiene `pom.xml`, estructura Maven y las clases Java solicitadas.

Construir:

```bash
mvn clean package
```

Archivos principales:
- `pom.xml` - configuración Maven
- `src/main/java/com/tienda/model` - clases Java

Pasos para subir a GitHub:

```bash
git init
git add .
git commit -m "Proyecto base: pom + clases iniciales"
git branch -M main
git remote add origin <URL-del-repositorio>
git push -u origin main
```
